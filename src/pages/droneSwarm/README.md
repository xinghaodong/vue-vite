# 无人机集群编队设计与表演系统 (DroneSwarm Studio) 工程设计手册

> **工程使命**：基于 Web 现代化渲染体系（2D PixiJS 矢量高锐度渲染 + 3D Three.js 空间点云夜空仿真），构建高内聚、工业级、支持千架次无人机协同编排的数字化设计平台。本手册规范了模块工程拓扑、核心渲染与算法分层，并完整收录基于 SwarmStudio 工业原版的逆向推导与技术对标标准。

---

## 一、 模块定位与工程架构拓扑

本系统位于前端工程 `src/pages/droneSwarm`，采用“状态数据层 (`types`) - 渲染驱动引擎层 (`composables`) - 业务界面组件层 (`components`) - 总控容器 (`index.vue`)”的四层模块化架构：

```
src/pages/droneSwarm/
├── index.vue                      # 编队系统主视口容器（顶栏工具、工作台切换、分镜总控）
├── components/
│   ├── Editor2D.vue               # 2D 矢量点阵工作台（PixiJS 画布装配、圈选、微调、快捷对齐）
│   ├── Player3D.vue               # 3D 仿真夜空视口（Three.js 场景装配、夜空氛围、灯光预览）
│   ├── TimelineBar.vue            # 分镜编排与声光电协同时间轴
│   ├── MotifLayerPanel.vue        # 构型列表与素材图层管理树（显隐、锁定、颜色通道）
│   └── ImageProcessingModal.vue   # 图像转点阵向导模态框（二值化、轮廓提取、全局弧长采样）
├── composables/
│   ├── usePixiEditor.js           # 2D 渲染引擎：高锐度矢量点阵渲染、视口平移缩放、碰撞检测
│   └── useThreeStage.js           # 3D 渲染引擎：InstancedMesh 批量发光点云、灯光通道、相机漫游
└── types/
    └── swarm.js                   # 工业数据模型定义（DronePoint, Motif, Layer, Project 标准协议）
```

### 1. 核心数据流驱动模型 (`types/swarm.js`)
* **单机原子实体 (`DronePoint`)**：包含唯一物理机位编号 `id`、物理空间坐标 `(x, y, z)`、机载 RGBW 灯光色彩 `color`、发光强度 `intensity` 与状态标志（`selected`, `locked`）；
* **构型基元 (`Motif`)**：分镜内的原子编队形态，绑定独立图层树、机队架次规模、包围盒物理包络尺寸与机载灯光参数；
* **分镜剧本 (`Cue / Scene`)**：记录时序推进节点，包含起止时间、定格构型快照、过渡时长 (`transitionTime`) 与变轨策略；
* **工程总控根模型 (`SwarmProject`)**：工程元数据、安全间距阈值 ($D_{\min} \ge 1.5\text{m}$)、场地尺寸（如 $200\text{m} \times 200\text{m}$）与三元打包索引。

### 2. 双引擎渲染分离机制
* **2D 编辑态 (PixiJS)**：侧重高精平面几何微调、框选/套索、单像素骨架对齐与间距巡检，利用 WebGL 2D 批处理渲染保证 2000+ 点位 60fps 丝滑交互；
* **3D 仿真态 (Three.js)**：侧重实机空间体量感知、InstancedMesh 发光无人机渲染、城市夜景底衬、地面起飞矩阵与变轨航迹回放。

#### 3.1 Step 1：生成预处理图（Preprocess）
* **核心参数控制**：
  * **快速预设**：提供下拉选项，默认选中 `精准图形（推荐）`；

  * **画布辅助**：支持 `隐藏原图`、`锁定原图`，以及 `按比例展开` 画布视口。

  * 图像预处理微调：亮度滑块、对比度滑块、反相勾选框；

* **对应截图证据**：[frame_09s.jpg](file:///e:/nest/mynest1/vue-vite/vue-vite/swarm-video-frames/import-layout/frame_09s.jpg)。

#### 3.2 Step 2：生成中间图（Intermediate Vectorization & Skeletonization）
* **四大核心识别模式**：
  1. **白色**：提取纯白高亮像素特征；
  2. **骨架（Skeleton）**：执行**单像素骨架细化算法（Zhang-Suen 或 Medial Axis Thinning）**，将粗笔触提炼为单像素骨架中轴线，保证布点不出现重叠双轨；
  3. **轮廓（Contour）**：执行闭合边缘拓扑追踪，提取有序折线几何路径（视频中高亮选中）；
  4. **圆点（Dots）**：提取特征圆点或网格点。
* **三维视图对比体系**：
  * **视效对比**：`结果` / `叠加` / `差异` 视图无缝切换；
  * **通道对比**：`输入` / `输出` / `混合` 单选对比；
* **素材树联动**：生成中间图后，左侧素材列表自动构建分层树结构：`线稿.png -> [原图, 预处理图, 中间图]`，各层具备独立的显隐与锁定状态控制。
* **对应截图证据**：[frame_13s.jpg](file:///e:/nest/mynest1/vue-vite/vue-vite/swarm-video-frames/import-layout/frame_13s.jpg) 与 [frame_17s.jpg](file:///e:/nest/mynest1/vue-vite/vue-vite/swarm-video-frames/import-layout/frame_17s.jpg)。

#### 3.3 Step 3：生成构型与点阵排布（Agent Placement）
* **三大生成模式**：
  1. `按间距`：固定无人机安全距离，由轮廓总周长推导所需无人机总架数；
  2. `按点数`：固定机队总架数（如 800/1600 架），由全局弧长配额算法自动计算步长；
  3. `圆心画布`：基于中心发散的同心圆点阵生成模式。
* **三大布点策略**：
  1. `随形（Contour Following）`：沿着折线/骨架切线方向做累积弧长等距分布（核心推荐）；
  2. `正交（Orthogonal Grid）`：笛卡尔网格离散采样；
  3. `六边形（Hexagonal Packing）`：蜂窝最密空间堆积。
* **关键工业物理参数**：
  * **点间距（Distance）**：默认 `1.5 m`；
  * **无人机物理尺寸（Drone Size）**：如 `0.5 m`（机身外轮廓物理包络）；
  * **智能安全推荐**：系统根据机身尺寸自动给出安全推荐（如 `建议 0.85 m`），并支持一键 `[套用]`。
* **自动化工程开关**：
  * `显示中间图`、`布点后隐藏`、`布点后锁定`，生成完毕后自动保持画布整洁。
* **对应截图证据**：[frame_21s.jpg](file:///e:/nest/mynest1/vue-vite/vue-vite/swarm-video-frames/import-layout/frame_21s.jpg)。

### 4. 视频 C 逆向解析：2D 点阵编辑器的局部剪枝与连续曲线等距重排算法

视频 C（`调整间距-1_1789711038027.mp4`）展示了 2D 点阵生成之后的**工业级微调与连续曲线重采样工作流**。在商业级无人机编队工程中，这是从“粗胚构型”走向“实机安全交付”的核心关键环节。

└────────────────────────────────────────────────────────────────────────────────────────┘

#### 4.1 工业背景与算法痛点（为什么必须有此工具）
1. **自动算法的局限（80/20 定律）**：自动图像二值化与骨架细化（OTSU + Zhang-Suen）能快速建立全局骨架，但在笔触分叉、转折缝隙处极易产生密集簇点（间距 $< 1.0\text{m}$），严重违反飞行安全规范（$D_{\min} \ge 1.5\text{m}$）。
2. **人工点选拖拽的成本灾难**：若完全依赖设计人员手工挪动点位，不仅极为耗时，且人工无法保证连续曲线上机身间距的数学严格等距。
3. **等量重排（$N \to N$ 守恒）**：在保持当前分镜该线条无人机配额严格守恒的前提下，沿着拟合的连续样条重采样，2 秒内消解局部疏密不均。

#### 4.5 离散计算几何数学模型推导
1. **有序点列拓扑重建**：
   通过手势轨迹的时间戳与距离投影确定离散点列的拓扑走向：
   $$\mathcal{P}_{\text{ordered}} = [P_1, P_2, \dots, P_N], \quad \text{其中 } t(P_1) < t(P_2) < \dots < t(P_N)$$
2. **向心 Catmull-Rom 样条拟合（Smoothness = 0.5）**：
   曲线段参数化采用向心幂次 $\alpha = 0.5$：$t_{i+1} = t_i + \|P_{i+1} - P_i\|_2^{0.5}$，数学上严格杜绝大曲率转折处的自交与 Runge 突变。
3. **累积弧长积分与参数反查**：
   数值计算总弧长 $L = \int_{0}^{1} \|\mathbf{C}'(u)\|_2 \, du$；  
   目标等距弧长序列为 $s_k = \frac{k - 1}{N - 1} \cdot L$（$k = 1, \dots, N$）；  
   通过二分逼近求得 $t_k$ 使得 $S(t_k) = s_k$，输出严格等距的新物理坐标 $P_k^{\text{new}} = \mathbf{C}(t_k)$。

#### 5.4 渐变物理空间正交投影与分段插值数学模型推导
设渐变控制轴由起始物理锚点 $\mathbf{P}_{\text{start}} = (x_0, y_0)$ 与终止物理锚点 $\mathbf{P}_{\text{end}} = (x_1, y_1)$ 构成，轴线方向向量为 $\vec{\mathbf{V}} = \mathbf{P}_{\text{end}} - \mathbf{P}_{\text{start}}$。
1. **正交空间投影与标量归一化**：
   对于任意无人机点位 $\mathbf{P}_i = (x_i, y_i)$，计算其在渐变轴向量上的正交投影标量：
   $$t_i = \frac{(\mathbf{P}_i - \mathbf{P}_{\text{start}}) \cdot \vec{\mathbf{V}}}{\|\vec{\mathbf{V}}\|^2}$$
   若未勾选 `循环`（Clamp 模式）：
   $$\tilde{t}_i = \max\left(0, \min\left(1, t_i\right)\right)$$
   若勾选 `循环`（Repeat 模式）：
   $$\tilde{t}_i = t_i - \lfloor t_i \rfloor$$
2. **多色标序列分段线性插值（Piecewise Linear Color Interpolation）**：
   设有序色标集合为 $\mathcal{S} = \{(u_1, \mathbf{C}_1), (u_2, \mathbf{C}_2), \dots, (u_K, \mathbf{C}_K)\}$，其中 $0 \le u_1 < u_2 < \dots < u_K \le 1$。  
   对于投影标量 $\tilde{t}_i$，二分定位其所属色标区间 $[u_k, u_{k+1}]$，其相对内插权重为：
   $$\alpha = \frac{\tilde{t}_i - u_k}{u_{k+1} - u_k}$$
   在感知均匀的线性色彩空间计算该无人机点位最终分配的 LED 色彩：
   $$\mathbf{C}(\mathbf{P}_i) = (1 - \alpha) \cdot \mathbf{C}_k + \alpha \cdot \mathbf{C}_{k+1}$$

#### 6.1 三元资产解耦打包标准（源文件 + 预览包 + 封面图）
在商业级编队中，整套工程包含数千架无人机的空间航迹、灯光时钟序列与参考图素材，直接推送单一大文件会导致浏览器卡死与带宽雪崩。SwarmStudio 在弹窗中严格将工程拆解为**三元独立分包**：
1. **源文件（Source Project File, 0.33 MB）**：
   * 包含母本数据模型、各构型图层树、所有无人机精确三维物理坐标、RGBW 灯光序列及时间轴事件；
   * 对应实飞与高精编辑，仅在打开本地工程时由客户端下载解析。
2. **预览文件（Compact Preview Stream, 0.08 MB）**：
   * 仅提取 5 秒动态时序的归一化空间点云坐标与发光强弱；体积压缩率高达 **75%**；
   * 专供工作中心卡片浮动预览、移动端审批及客户快速看板播放，实现 0 秒极速冷启动。
3. **封面图（Viewport Snapshot, 0.05 MB）**：
   * 点击弹窗中的 `[从当前视窗截图]` 按钮，底层通过 WebGL / PixiJS 离屏 Canvas 生成轻量快照；
   * 专供工程列表的静态缩略图展示。
* **对应截图证据**：[frame_06s.jpg](file:///e:/nest/mynest1/vue-vite/vue-vite/swarm-video-frames/sync-project/frame_06s.jpg)。

#### 6.2 6 步自动化同步传输流水线（`0/6` 状态机推导）
点击 `[同步工程]` 按钮后，系统进入状态机进度提示 **`同步通道已就绪，正在传送工程文件 0/6`**：
* **Stage 1 (Snapshot)**：抓取视口渲染帧并转码为封面图资源；
* **Stage 2 (Serialize & Hash)**：序列化源工程数据并计算 SHA-256 内容哈希；
* **Stage 3 (Preview Extraction)**：抽取 5 秒有损点云预览流；
* **Stage 4 (Channel Handshake)**：向后端 NestJS / 云端协同服务申请带鉴权的时效性上传凭证；
* **Stage 5 (Chunk Upload)**：分块并发传输源文件、预览文件与封面图；
* **Stage 6 (Registry & Lock Release)**：云端写入元数据索引表，更新工程版本号并广播变更事件。
* 成功后顶部弹出全局 Toast：**`✔ 已同步 "线稿工程" 到企业 Space`**，左上角工程名原子更新为 `线稿工程`。

#### 6.3 工作中心工程矩阵与企业协作并发锁（Collaborative Locking）
