## 一、 系统架构总览与核心设计模式

整个表单引擎遵循工业级低代码设计规范（解耦为：**物料注册层**、**设计态画布**、**运行态渲染器**、**公式计算引擎**）：

```text
src/pages/formDesign/
├── widgets/                             # 🌟 1. 物料注册中心 (Widget Registry)
│   ├── index.js                         # 物料注册表统一入口 (导出 fieldWidgets, containerWidgets, getWidget, registerWidget)
│   └── settings/                        # 各组件专属属性面板 (高内聚、自包含)
│       ├── InputSetting.vue             # 文本类配置 (字数、计数、清除、预设正则校验规则)
│       ├── NumberSetting.vue            # 数字类配置 (最小值、最大值、步长、精度、加减按钮)
│       ├── SelectSetting.vue            # 选择类配置 (静态选项列表、动态 API 接口、默认当前人)
│       ├── DatePickerSetting.vue        # 日期类配置 (展示格式 format、绑定格式 valueFormat)
│       ├── SwitchSetting.vue            # 开关类配置 (开启/关闭提示文字)
│       ├── UploadSetting.vue            # 附件类配置 (文件后缀白名单、张数、文件限额、提示文案)
│       └── GridSetting.vue              # 栅格类配置 (分栏间隔 gutter、列数、24 栅格比例滑块)
│
├── components/                          # 🌟 2. 运行态渲染器 (业务页面 / 工作流 / 审批抽屉直接复用)
│   ├── DynamicForm.vue                  # 表单总控容器 (校验引擎、响应式数据同步、全局公式计算、API 加载)
│   ├── FormItemRenderer.vue             # 递归表单项解析器 (核心：递归调用自身，消灭 50% 重复模板)
│   └── widgets/
│       └── FileUploadWidget.vue         # 自包含的发票/附件卡片列表组件 (防闪烁、PDF徽标、独立预览)
│
├── designer/                            # 🌟 3. 设计态工作区
│   ├── DesignItemRenderer.vue           # 画布递归设计项 (严格单根原生 DOM、手柄拖拽、高亮、删除、列内嵌套)
│   └── ComputedFieldSetting.vue         # 双模式计算字段面板 (简易向导点选 + 排他网关同款字段胶囊)
│
├── utils/
│   └── formula.js                       # 🌟 4. 内置安全公式函数库 (DATEDIF, SUM, MULTIPLY, IF, ROUND)
│
└── formDesign.vue                       # 🌟 5. 设计器总入口 (左侧物料库 + 中间画布 + 右侧属性栏)
```

## 二、 今日已完成的核心重构里程碑

1. **消灭 1000+ 行重复模板（DRY 递归原则）**：
   - 抽出 `FormItemRenderer.vue` 与 `DesignItemRenderer.vue`，无论是普通字段还是栅格列内部，全部走统一递归入口。
2. **彻底根治拖拽死锁故障**：
   - 为设计项确立严格的**单一根 DOM 元素**，杜绝 Vue 3 Fragment 多根节点导致 Sortable.js 追踪丢失的问题；
   - 引入高熵随机唯一 ID 生成器 (`${type}_${timestamp}_${random}`)，杜绝克隆 ID 冲突；
   - 拖拽克隆执行严格深拷贝，防止跨组件引用污染。
3. **属性面板完全模块化解耦**：
   - 右侧属性面板由动态组件驱动：`<component :is="activeSettingComponent" />`，消灭几百行堆砌的 `v-if`。
4. **新增专用的【数字输入 (number)】物料**：
   - 基于 `el-input-number`，支持 `min`、`max`、`step`、`precision`，数据天然为 `Number` 类型，彻底规避计算时的 JS 字符串拼接 Bug。
5. **单行文本支持【格式校验规则 (ruleType)】**：
   - 内置纯数字、正整数、手机号、邮箱、身份证正则引擎，提交时自动校验并友好提示。
6. **双模式计算字段引擎（向导 + 排他网关同款）**：
   - **简易向导**：下拉选择“日期相减算天数”、“数值乘法”、“多项累加”，0 代码自动生成公式；
   - **高级公式**：类似排他网关，提供公式输入框 + 常用字段蓝色药丸 Tag + 内置函数绿色药丸 Tag，点击直接插入；
   - **底层公式库**：内置 `DATEDIF(start, end) + 1`、`SUM`、`MULTIPLY`、`ROUND`、`IF`，自动判空防报错，彻底告别原生毫秒除法。
7. **彻底清除脏兼容与业务硬编码**：
   - 彻底删除 `field.id === 'sqr'` 等业务硬编码，转为纯 Schema 协议驱动：
   - 通过 `defaultCurrentUser: true` 开关或 `apiUrl: '/internalusers/getUserInfo'`，实现新建填单自动回填登录人、审批回显按历史 ID 反查真实申请人。

## 三、 主流表单设计器物料矩阵全貌

### 1. 已实现物料
* **基础录入**: 单行文本 (`input`)、多行文本 (`textarea`)、数字输入 (`number`)
* **选项字典**: 下拉选择 (`select`)、单选框组 (`radio`)、多选框组 (`checkbox`)
* **日期时间**: 日期选择器 (`date-picker`)、开关 (`switch`)
* **文件凭据**: 附件上传 (`upload` / `file-upload`)
* **布局容器**: 栅格布局 (`grid`)

### 2. 待扩展的核心物料规划（按优先级）

| 优先级 | 物料类型 | 组件标识 | 核心业务场景与价值 |
| :--- | :--- | :--- | :--- |
| **P0 (最核心)** | **★ 子表单 / 明细表格** | `subform` / `table` | **【支撑报销/采购的关键物料】** 支持“+添加一行明细”（如费用明细：项目、金额、发票），行内字段可独立计算，底部自动汇总合计。 |
| **P1 (高频容器)** | **标签页** | `tabs` | 针对 20+ 个字段的大型表单，按页签分页展示（如：基本信息 / 财务报销 / 附件清单）。 |
| **P1 (高频容器)** | **卡片分组** | `card` | 带标题和边框的聚合卡片（如将“紧急联系人”、“出差行程”信息框在一起）。 |
| **P1 (高频字段)** | **日期区间** | `date-range` | 一键选择起止时间，输出数组 `[start, end]`，避免放两个单独的日期框。 |
| **P1 (高级录入)** | **评分** | `rate` | 满意度评价、绩效打分（1~5 星）。 |
| **P1 (高级录入)** | **滑块** | `slider` | 完成度、百分比进度（0% ~ 100%）。 |
| **P1 (级联选项)** | **级联选择** | `cascader` | 省市区三级联动、多层级部门组织选择。 |
| **P2 (高级审批)** | **电子签名** | `signature` | Canvas 手写板在线签字确认，输出图片或 Base64。 |
| **P2 (高级文档)** | **富文本** | `rich-text` | 带加粗、插图、排版的正式合同、公告说明。 |
| **P2 (排版辅助)** | **分割线** | `divider` | 纯线条或带文字标题的水平分割线，清晰分隔表单各区块。 |

## 四、 联动与计算体系规范

### 1. 双模式计算字段架构（Single Source of Truth）
无论是“向导生成”还是“自定义公式输入”，组件 Schema 中统一存储：
```json
{
  "isComputed": true,
  "computeMode": "wizard", // 或 "custom"
  "wizardConfig": {
    "scene": "dateDiff",
    "startDate": "startDate",
    "endDate": "endDate",
    "includeToday": true
  },
  "dependencies": ["startDate", "endDate"],
  "computedExpression": "DATEDIF(startDate, endDate) + 1"
}
```

### 2. 内置安全公式库清单 (`formula.js`)
* `DATEDIF(start, end, unit = 'd')`: 自动转换字符串/时间戳，安全计算天数差（内置空值防护，不报错、不出现 `NaN`）；
* `SUM(...args)`: 自动数值转换累加，杜绝 JavaScript 字符串拼接 Bug（`"25" + 5 = "255"`）；
* `MULTIPLY(...args)`: 安全乘法并修约精度；
* `ROUND(val, precision)`: 安全四舍五入；
* `IF(condition, trueVal, falseVal)`: 三元条件分支。
